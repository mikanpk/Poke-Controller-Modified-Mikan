## SV

### 色孵化

#### 本プログラムの実行前に完了しておく準備

- ボックス名と中身
  - きじゅん：ボックス内左上の1列目・2列目に親ポケモンを配置する
  - たまご：0匹の状態にする
- 手持ち
  - 孵化要員1匹のみにする
- 場所
  - ゼロゲートにそらととぶをした状態の場所で開始する
- 道具
  - スーパーピーナッツバターサンドの材料を複数セット
  - 孵化させたい個数分は用意する
    - ピーナッツバター
    - バター
    - バナナスライス
- 設定
  - 話のはやさ：はやい
  - カメラ サポート：する
  - カメラ 補間ゆっくり：ふつう（影響ないかも）
  - カメラ 距離：どれでも
  - おまかせレポート：しない
  - 言語：漢字（別言語の場合、テンプレート画像の差し替えが必要）

#### ソース

- ファイル
  - PkmnSV_AutoHatching.py メインとなるプログラム
  - ImageProcPythonCommandAddin.py 既存の画像処理プログラムの拡張版
- 使用画像
  - pkmnSV_AutoHatching_img フォルダ

#### 処理の概要

1. 手持ちのたまご数を確認
2. たまごなしの場合
   1. 手持ちを変更（孵化要員=>親）
   2. ピクニックを行う
   3. サンドイッチを作る
   4. たまごを取得する
   5. 手持ちを変更（親=>孵化要員）
   6. 手持ちにたまごを追加
3. たまご孵化作業
   1. 手持ち数分孵化するまで走行
   2. 手持ちを変更（孵化後=>たまごボックスへ）
   3. ボックス内にたまごがある場合
      1. 手持ちにたまごを追加
      2. 孵化作業を繰り返す
4. ボックスチェック（色違いマーク有無・ステータスの確認）
   1. ボックス内を確認
   2. 条件一致するポケモンがいた場合
      1. 隣のボックスへ移動
      2. それ以外のポケモンをにがす
      3. レポートを書く
      4. 1から繰り返し
   3. 条件一致するポケモンがいなかった場合
      1. ソフトリセット
      2. 1から繰り返し
